# DataVortex — Data Dictionary
_Generated by `scripts/build_data_dictionary.py` from `data/processed/*.parquet`._

Source-column meanings for the raw files are in [`01_forensic_audit.md`](01_forensic_audit.md); this document describes the **cleaned analytical layer** the dashboard and agent read.

Naming convention: `*_original` holds the untouched source value, `*_canonical` / `*_clean` holds the normalized value, and boolean `*_invalid` / `*_missing` / `*_unresolved` columns are quality flags. Original values are never discarded.
